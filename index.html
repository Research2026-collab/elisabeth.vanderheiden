HTML · ToolCheck Inklusion Haushaltsbuch +
Eine Anwendung in Einfacher Sprache zum Eintragen von Einnahmen und Ausgaben. Sie bietet eine monatliche Übersicht, einen Sechs-Monats-Vergleich und eine grafische Aufschlüsselung der Ausgaben. Alle Daten bleiben lokal auf dem Gerät.

HTML · ToolCheck Inklusion Mein Geld im Blick +
Eine digitale Haushaltsbuch-App in Einfacher Sprache. Nutzer:innen können Einnahmen und Ausgaben eintragen, Kategorien auswählen und sehen, wie viel Geld im Monat übrig bleibt. Die Daten werden lokal gespeichert und können exportiert werden.
